# Minecraft Java版矿物描边材质

## 目的

制作这个包是为了解决矿物不够醒目的问题，给每种矿物方块都加上了对应掉落物品矿石醒目的边缘

## 更新

随着游戏版本出矿物的速度更新而更新（真的吗？），我很有可能会忘记更新这个包（正解）。

## 制作工具＆使用贴图

使用Adobe Photoshop 2020制作，基于Minecraft 1.17的矿物贴图，没有制作旧版材质贴图的意愿。
